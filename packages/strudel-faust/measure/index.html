strudel-faust — measurements

Four numbers decide the shape of this package, and none of them is guessable. Run these before the pattern-facing code exists, not after. Serve from the composing dev server (npm run dev, then /packages/strudel-faust/measure/) so that /vendor/faustwasm/index.js resolves. One at a time — the buttons disable while a measurement runs, because concurrent runs share the tap and invent plausible numbers rather than failing visibly.
